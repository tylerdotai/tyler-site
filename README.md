## About The Project

This is the source for [tylerdotai.com](https://tylerdotai.com) — a personal site built to document what I build, who I community with, and what I create.

**Currently:** IT Support Associate (L3) at Amazon by day. AI agent builder by night. Exceeds High Bar.

**The origin story:** March 2024, Amazon put me on a Performance Improvement Plan. Three months to turn it around or get cut. Instead of panic-applying to jobs, I got curious about AI agents. Built a crew of AI subagents to handle the PIP tasks. They didn't save my job — but they showed me what was possible when you stop using AI as a chatbot and start treating it like a workforce. Got rated "Exceeds High Bar" on my mid-year review. Got a raise. Decided: this is the thing. Let's go all in.

**The community:** I run the [Agent Builders Club](https://clawplex.dev) — 600+ members across 6 DFW locations learning to build AI-powered workflows. No fluff. Just builders showing each other what works.

**The creative work:** 30 days with the Sony ZV-E10. Every clip is a real moment. No crew. No script.

## Getting Started

This is a static Astro site. No database, no server-side rendering (mostly).

### Prerequisites

- Node.js 25+
- npm 11+

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/tylerdotai/tyler-site.git
   ```
2. Install dependencies
   ```sh
   npm install
   ```
3. Start the dev server
   ```sh
   npm run dev
   ```
4. Build for production
   ```sh
   npm run build
   ```
